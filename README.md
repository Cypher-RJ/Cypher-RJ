## ✨ Featured Projects

### 🐚 [minishell](https://github.com/Cypher-RJ/42Lisboa_Minishell)
A custom Unix shell written in C — one of the most complex and rewarding 42 projects!
- 🔗 Command parsing, built-ins, pipes, and redirections
- ⚙️ Deep dive into process management with `fork`, `execve`, and `wait`
- 🔤 Environment variable handling, signals, and heredocs

### 🎮 [cub3D](https://github.com/thob3301/cub3d/tree/rcesar-d)
A 3D raycasting engine inspired by the legendary Wolfenstein 3D, built in C!
- 🖼️ Real-time rendering using raycasting math and a graphics library
- 🕹️ Full player movement, map parsing, and texture rendering
- 🧮 Strengthened understanding of vectors, angles, and game loops
